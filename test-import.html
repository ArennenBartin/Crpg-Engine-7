Sprite Import Feature Implementation

✅ Completed Features

  • Import button added to SpriteCreator UI header
  • File input handling for PNG/WEBP images
  • Image quantization to 48x48 grid with palette extraction
  • Preview modal showing imported image before conversion
  • Error handling for unsupported formats and oversized images
  • Color quantization using game's palette (11 colors + transparency)
  • Automatic sprite creation with proper naming

🎨 Game Palette Used

  • #1A1410 - warm near-black outline
  • #D9A47E/#B5805C - skin colors
  • #EDE4CE/#C7B999 - linen colors
  • #8A6B3C - bronze
  • #D9A648 - votive gold
  • #74815B - olive
  • #3D4666 - indigo
  • #B26A4B - terracotta
  • #A7D9DC - star-glass cyan
  • #7A1B26 - crimson

📋 Implementation Details

The sprite import feature:

  • Accepts PNG and WEBP image files up to 5MB
  • Scales all images to 48x48 pixels
  • Quantizes colors to match the game's aesthetic palette
  • Preserves transparency (alpha < 128 becomes transparent)
  • Shows a preview before finalizing the import
  • Creates a new sprite with automatic naming
  • Integrates seamlessly with existing sprite editor

🚀 Ready to Use

The import feature is now available in the SpriteCreator component. Users can click the "Import" button in the header, select an image file, preview the conversion, and add it to their sprite library.
